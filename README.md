#  Bottle Design Project

# Ergonomic Bottle Design using SolidWorks

## Overview
This project presents the design and 3D modeling of an ergonomic bottle using SolidWorks. The bottle geometry was designed with both aesthetics and usability in mind, focusing on grip comfort, symmetry, and manufacturable structure.

The model contains:
- Curved bottle body
- Threaded neck region
- Grip grooves
- Hollow interior structure
- Smooth transitions and rounded surfaces

This project helped in understanding advanced solid modeling workflows and surface refinement techniques.

---

## Design Objectives
The main objectives of the project were:
- Create a visually appealing bottle structure
- Improve ergonomics through grip grooves
- Maintain geometric symmetry
- Practice advanced CAD operations

---

## Features Used
- Revolve Boss/Base
- Extruded Cut
- Shell Feature
- Fillet
- Circular Pattern
- Reference Geometry
- Surface Refinement

---

## Modeling Workflow
1. Sketched the bottle side profile.
2. Used revolve operation to generate the main body.
3. Applied shell feature for hollow interior.
4. Designed threaded neck structure.
5. Added grip grooves using cuts/patterns.
6. Applied smooth edge finishing using fillets.
